# i forgor

A monochrome game about temporary things. Move through five passages as the board erodes; what is gone stays gone.

Play on [itch.io](https://kirbx01.itch.io/i-forgor).

## Controls

| Input | Action |
| --- | --- |
| `W` `A` `S` `D` or arrow keys | Move |
| `R` | Restart passage |
| `Esc` | Open menu |
| `F11` | Toggle fullscreen |
| `Tab` / `Enter` | Navigate menus |
| Mouse | Click buttons and links |
